# Claude instructions

Read and follow [AI-COLLABORATION.md](./AI-COLLABORATION.md) before making changes.

This is the BarMisaki VRChat venue ordering system. It uses React, TypeScript, Vite, Firebase Authentication, Cloud Firestore, Vitest, and GitHub Pages.

Use a `claude/<task-name>` branch created from the latest `origin/main`. Do not work directly on the Codex worktree or push to `main`. Preserve live Firebase data and do not deploy or change production data without explicit user approval.

When finished, commit the focused change and provide the handoff information required by `AI-COLLABORATION.md` so Codex can review and integrate it.
